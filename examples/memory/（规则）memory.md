# 记忆库规矩（示例）

## 四层

| 层 | 文件 | 读取时机 | 预算 |
|---|---|---|---|
| L0 | `AGENTS.md` | 每轮注入 | ≤ 2.6 KB |
| L1 | `memory/MEMORY.md` | 每会话一次 | ≤ 15 KB，单行 ≤ 200 字 |
| L2 | `memory/（标签）名字.md` | 命中才读 | ≤ 4k token / 篇 |
| L3 | `memory/（标签）xxx-detail/` | 几乎不读 | 不限 |

## 写入流程

1. 内容写进对应主题记忆（一篇一个文件，名称 `（标签）名字.md`）。
2. 在 `MEMORY.md` 对应分区加**一行**索引：`- [标题](文件) — ≤60 字提示`。
3. 超过 4k token 或 200 行，就补 `## 当前状态（先读这里）` 头部摘要。
4. 跑 `python memory-budget.py`，必须 `[OK]`。

## 命名

- 分类前置：`（环境）/（技术）/（项目）/（规则）…`
- 文件名与 frontmatter 的 `name` 同形。
- 冷档目录同样前置：`（技术）build-issues-detail/`。

## 禁令

- 细节不进索引；资料不进 L0；详情不堆速查表；同一主题不开第二个文件。
