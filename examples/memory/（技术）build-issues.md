# 构建常见问题（示例）

> 这是「速查表」的写法：**主表只放结论**（一句话 + 去哪里看详情），
> 完整复盘、堆栈、排查过程全部沉到 `（技术）build-issues-detail/`。

## 速查表

| 关键词 | 结论 | 详情 |
|---|---|---|
| 构建超时 | 默认 60s 太短，长任务走后台作业 | [2026-01-04](（技术）build-issues-detail/2026-01-04-timeout.md) |
| 缓存命中率低 | 把依赖安装和源码拷贝拆成两层 | — |
| 产物变小但运行报错 | 多半是动态导入被静态分析漏掉 | — |
| 并行构建偶发失败 | 两个任务写同一个临时目录，加进程 id | — |

## 怎么用

1. 报错先在本表搜关键词，命中就看最后那列的详情。
2. 表里没有的，先按「最小复现」排查，别直接改配置。
3. 排查完把**结论压成一句话**回填本表，详情写进 detail。
