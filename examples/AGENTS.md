# 常驻规则（L0 · 示例）

> 这个文件每一轮都会随系统提示注入，所以它只放两样东西：**不可违反的规则** 和 **去哪里查的指针**。
> 环境清单、路径表、项目进度这类「资料」一律进 `memory/`，不要写在这里。

## 硬规则（不可违反）

- 动手前先查记忆索引；命中就读对应主题记忆，不要凭印象。
- 同一件事失败 2 次必须上报，不自行绕过或改需求。
- 新建记忆条目 / 新目录前先说清「为什么建、放哪、叫什么」，得到确认再写。
- 任何删除、覆盖、跨目录移动，先确认目标路径；不确定就问。
- 收尾跑 `python memory-budget.py`，必须 `[OK]` 才算写完。

## 去哪查（本文件只留指针）

| 想查什么 | 去哪 |
|---|---|
| 运行环境 / 依赖 / 路径 | `memory/（环境）runtime.md` |
| 报错与踩坑 | `memory/（技术）build-issues.md` |
| 记忆库自身的规矩 | `memory/（规则）memory.md` |
| 长期项目进度 | `memory/（项目）<名字>.md` |

## 开场动作

1. 读 `memory/MEMORY.md`（索引，≤15 KB）。
2. 任务涉及哪个关键词，再读对应的那一篇，**不要全库通读**。
3. 需要细节时再进 `*-detail/`，那里是冷档。
